## OS별 대응

### macOS

- **zip은 Finder에서 더블클릭으로 풉니다.** 다른 압축 프로그램이나 Windows에서 푼 뒤 옮기면 실행 권한이 빠져 열리지 않을 수 있습니다.
- **처음 실행하면 "확인할 수 없습니다" 경고가 뜹니다.** [완료]를 누르고(휴지통 아님) 시스템 설정 → 개인정보 보호 및 보안 → 아래쪽 "checker-macos이(가) 차단되었습니다" 옆 [그래도 열기] → Mac 암호 → 다시 [그래도 열기]. 한 번만 하면 됩니다.
- **더블클릭하면 터미널 창이 같이 열립니다.** 채점기 본체이므로 검사가 끝날 때까지 닫지 마세요.
- M1 이후 Mac과 Intel Mac 모두 같은 파일을 씁니다.

### Windows

- **zip을 오른쪽 클릭 → [압축 풀기] 후 실행합니다.** zip 안에서 바로 실행하면 채점기가 멈추고 압축을 풀라고 안내합니다.
- **"Windows의 PC 보호" 창이 뜨면** [추가 정보] → [실행].
- **백신이 파일을 지웠다면** Windows 보안 → 바이러스 및 위협 방지 → 보호 기록 → [디바이스에서 허용] 후 다시 받습니다.

### Linux

- 압축을 풀고 터미널에서 `./checker-linux-amd64` 를 실행합니다.

## 채점기가 기록하는 정보

검사 결과와 함께 컴퓨터 이름과 MAC 주소를 암호화해 기록합니다. 다른 사람의 컴퓨터로 대신 검사한 제출을 가려내기 위해서입니다. DB 비밀번호는 저장하지 않고, DB는 읽기만 합니다.



## 문의사항
프로그램 버그는 `sys@g.hongik.ac.kr` 로 아래 양식에 맞춰 보내 주세요. 과제 코드나 채점 결과에 대한 질문은 버그 문의가 아닙니다.

- **메일 제목**: `[DB 채점기 버그] 학번 이름`
- **첨부**: 문제가 보이는 화면 캡처, 그리고 결과 zip(`results` 폴더의 가장 최근 `submit_*.zip`)이 있다면 그 파일. zip 안에 채점 기록이 암호화돼 들어 있어 원인을 찾는 데 필요합니다.

```
1. 학번 / 이름:
2. OS와 버전 (예: macOS 15, Windows 11):
3. 실행한 채점기 파일 이름 (예: checker-macos, checker-windows-amd64.exe):
4. 증상 (무엇을 했을 때 무엇이 일어났는지):
5. 기대한 동작:
6. 화면이나 터미널 창에 나온 오류 메시지 (그대로 복사):
7. 다시 해도 똑같이 일어나나요? (예 / 아니오 / 가끔):
```

**DB 비밀번호는 메일에 적지 마세요.** 오류 메시지에 비밀번호가 보이면 지우고 보내세요.
